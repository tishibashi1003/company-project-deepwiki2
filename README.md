# 会社デモセールス議事録管理

このリポジトリは会社のデモセールスプロセスに関連する議事録をまとめ、アクセス可能な形で管理するためのものです。

## 目的

- 販売プロセスの透明性の確保
- 顧客とのコミュニケーション履歴の中央管理
- 営業チーム間の情報共有の促進
- ベストプラクティスと成功事例の文書化

## 構造

- `docs/` - 販売プロセスに関する一般的なドキュメントと手順
- `meetings/` - 議事録本体
  - `general/` - 内部ミーティングの議事録
  - `project/` - 顧客プロジェクトミーティングの議事録
- `company-profile.md` - 会社概要資料

## AI支援による情報整理

このリポジトリでは、AIを活用して議事録の要約や情報整理を行います。具体的には以下のような機能を実装しています：

- 複数の議事録から重要なポイントを抽出し、トピック別に整理
- 長期的なトレンドや顧客の要望パターンの分析
- 決定事項や次のアクションアイテムの自動抽出とタスク化
- 類似案件や過去の成功事例の関連付けと推奨

これにより、膨大な議事録から素早く必要な情報を見つけ出し、営業活動の効率化と品質向上を図ります。

## 貢献

チームメンバーは誰でも議事録を追加・更新できます。変更を加える前に最新版を取得するようにしてください。
