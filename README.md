# 会社デモセールス議事録管理

このリポジトリは会社のデモセールスプロセスに関連する議事録をまとめ、アクセス可能な形で管理するためのものです。

## 目的

- 販売プロセスの透明性の確保
- 顧客とのコミュニケーション履歴の中央管理
- 営業チーム間の情報共有の促進
- ベストプラクティスと成功事例の文書化

## 構造

- `docs/` - 販売プロセスに関する一般的なドキュメントと手順
- `meetings/` - 議事録本体
  - `general/` - 内部ミーティングの議事録
  - `project/` - 顧客プロジェクトミーティングの議事録
- `company-profile.md` - 会社概要資料

## 貢献

チームメンバーは誰でも議事録を追加・更新できます。変更を加える前に最新版を取得するようにしてください。
